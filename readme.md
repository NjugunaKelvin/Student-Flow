# Student Course Management System

A simple Java console application to manage students and their enrolled courses.

## Features

- Add students
- Add courses
- Enroll students in courses
- View all students with their course enrollments
- Built with core Java concepts:
  - Classes and Objects
  - Constructors
  - ArrayLists
  - Encapsulation
  - Exception Handling
  - Loops and Conditionals
  - Method Calling
  - Switch Statements

## Technologies

- Java (JDK 8+)
- IntelliJ IDEA / VS Code (or any Java IDE)
- Console-based UI (no GUI)
